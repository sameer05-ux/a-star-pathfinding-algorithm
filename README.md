# A* Pathfinding Visualizer

## Description
An implementation of the A* pathfinding algorithm utilising the octile 8-way movement system to calculate the heuristic. It allows users to find the shortest path in a grid with dimensions chosen by the user from a starting node to a target node and visually display the path via the command line.

## Features
- Allows user to select dimensions of the grid they would like to construct
- Allows users to enter a start node and a target node via the command line to compute the shortest path.
- Uses the octile distance heuristic function to accurately estimate whilst never overestimating the distance between the current node and target node.
- Graphically displays the grid via the command line, highlighting the computed shortest path.

## Prerequisites
- Python (version 3.x recommended)
